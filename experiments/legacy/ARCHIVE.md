# Archived research app

This directory preserves the scripts, UI, tests, configuration, README and package metadata immediately before the Gemini-only MVP cleanup. It includes the Qwen/CUDA encoder, FAISS server, BM25/hybrid comparisons, Jev/x-ray, reranking, planners, caches, agent browsing and earlier evaluation tools.

These files are outside the installed package and main test suite. They are historical experiments, not an alternative supported app. Paths in their scripts may still refer to the original repository layout; use their saved README and configuration as reference when revisiting an experiment. Existing local source PDFs, indexes and saved results remain in place and were not uploaded or regenerated by this cleanup.

The current app is documented in the root README.
